# Классическая эра 1.0

Новая версия браузерной стратегии «Классическая эра», написанная с нуля.
Данные игроков остаются в той же базе Supabase.

## Как устроено

Сайт без сборки: обычные HTML, CSS и JS-модули. Открываются прямо в браузере,
на Vercel ничего не собирается.

```
index.html            точка входа
src/config.js         адрес Supabase и публичный ключ
src/main.js           маршруты: #/ главная, #/cabinet кабинет, #/admin админ-панель
src/lib/              база, сессия и роли, форматирование, маршрутизатор
src/ui/               шапка, подвал, окно входа, иконки
src/pages/            главная, кабинет державы, админ-панель
src/styles.css        дизайн (чёрный и золото), src/app.css — дополнения
supabase/migrations/  изменения базы (применять по порядку)
design/               макеты дизайна
```

## Роли

| Роль | Кто | Что может |
|---|---|---|
| Команда проекта · Суперадмин | `v1_staff.level = superadmin` | всё, одобряет заявки админов, меняет правила одобрения |
| Команда проекта · Админ | `v1_staff.level = admin` | действия из списка «сразу»; остальные уходят на одобрение суперадмину |
| Игрок | есть своя держава или членство в державе | игра; редактирование страниц запрещено |
| Гость | все остальные и не вошедшие | просмотр и регистрация |

Права проверяет база, а не браузер: все действия команды идут через функции
`v1_admin_do` и `v1_admin_decide`. Какие действия админ делает сам, а какие
через одобрение, суперадмин настраивает в админ-панели, раздел «Правила одобрения».

## Запуск

1. Примените миграции в Supabase → SQL Editor, по порядку:
   `supabase/migrations/20261023_01_roles.sql`, затем `20261023_02_seed_team.sql`
   (во втором файле раскомментируйте тех, кого добавить в команду),
   затем `20261023_03_guide.sql` (гайдбук) и `20261023_04_rules.sql` (правила).
2. Локально: запустите «Запустить сайт.bat» (Windows, работает на встроенном PowerShell, ставить ничего не нужно) или `python3 -m http.server 8000` в папке проекта и откройте http://localhost:8000. Двойной щелчок по `index.html` не работает: браузер не грузит модули из файла.
3. Vercel: импортировать репозиторий, Framework Preset — Other, без команды сборки.
4. Вход через Google: в Supabase → Authentication → URL Configuration добавить адрес сайта в Redirect URLs.
